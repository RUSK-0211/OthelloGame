# Python Othello

Pythonで開発した、CLI（コマンドラインインターフェース）で操作するオセロゲームです。

1年次に制作した作品を、3年次に学んだ知識を活かしてリファクタリングしました。盤面の表示や操作性を改善し、機能ごとにモジュールを整理することで、読みやすく管理しやすいコードを目指しました。

## 制作背景

1年次のプログラミング学習で制作したオセロゲームを、現在の知識で見直し、改善に取り組みました。

制作当時の講評を振り返り、ゲームとしての分かりやすさや使いやすさを意識して改修しました。また、機能ごとにモジュールを整理し、保守性を意識した構成に見直しました。

## 主な機能

* **オセロの基本ルール**：石の配置、相手の石の反転、合法手の判定に対応
* **盤面表示の改善**：行・列の位置を分かりやすく表示し、石を置ける場所を `+` で表示
* **セーブ・ロード**：対局の状態を保存し、続きから再開
* **対局結果の出力**：対局終了後、盤面や勝敗などをHTML形式で出力
* **効果音**：石の配置、反転、対局終了、セーブ成功、エラーなどのイベントに応じて再生

## 実行方法

### 1. リポジトリをクローン

```bash
git clone <GitHubリポジトリのURL>
cd python-othello
```

### 2. 必要なライブラリをインストール

```bash
pip install -r requirements.txt
```

### 3. ゲームを起動

```bash
python main.py
```

※ 実際のディレクトリ構成や起動方法に合わせて、必要に応じてコマンドを変更してください。

## 操作方法

| 操作         | 内容        |
| ---------- | --------- |
| 座標入力（例：A1） | 石を置く場所を指定 |
| `S`        | セーブ       |
| `Q`        | ゲームを終了    |

※ 実際の入力仕様に合わせて調整してください。
